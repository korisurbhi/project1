## Student CRUD Website

This is a Student CRUD Website built using:

#### Frontend
- HTML
- CSS
- JavaScript

#### Backend
- Node.js
- Express.js

#### Database
- MongoDB

#### Template Engine
- EJS

### Features

- Add Student
- View Students
- Update Student Details
- Delete Student Records

### Open Website

http://localhost:5000/
